# Ихсан — намаз, Коран, дуа

Мобильное приложение для мусульман Кыргызстана и России: время намаза, Коран с переводом смыслов, дуа из Корана и Сунны, тасбих и направление на Кыблу. Бесплатно, без рекламы и регистрации. Интерфейс на русском и кыргызском языках.

> **Ихсан** — «совершенство в поклонении»: поклоняться Аллаху так, будто видишь Его (хадис Джибриля).

## Возможности

**Время намаза**
- Для Кыргызстана — официальное расписание Духовного управления мусульман Кыргызстана (API muftiyat.kg) с кэшем на 30 дней.
- Без интернета — астрономический расчёт (библиотека Adhan) с параметрами, подобранными под расписание муфтията: расхождение не больше 1 минуты (проверено по Бишкеку, Ошу и Караколу во все сезоны).
- Для России — метод ДУМ РФ (16°/15°), для остальных мест — Всемирная исламская лига или Умм аль-Кура.
- Ханафитский и шафиитский Аср, ручная поправка каждого намаза под свою мечеть.
- 19 городов или определение по GPS; правильная работа на высоких широтах.
- Время восхода, дата по хиджре с поправкой ±2 дня, сухур и ифтар в Рамадан.

**Уведомления**
- Локальные уведомления на 7 дней вперёд: в начале времени намаза и за 10/15/30 минут.
- Отключение уведомлений для отдельного намаза.

**Коран**
- Арабский текст (мусхаф Усмани), шрифт Amiri, три размера текста.
- Перевод смыслов: Э. Кулиев (русский) и Ш. Хакимов (кыргызский).
- Латинская транслитерация, аудио (Мишари Рашид аль-Афаси) по аятам и всей сурой.
- Места земного поклона (саджда) с учётом мазхаба.
- Продолжение чтения с последнего аята; открытые суры доступны без интернета.

**Дуа и зикры**
- 58 дуа из Корана и достоверных хадисов, у каждого указан источник с номером хадиса.
- Категории, поиск, избранное, копирование и отправка.

**Ещё**
- 99 имён Аллаха со значениями и «имя дня».
- Тасбих: цели 33/99/без ограничения, вибрация, свои фразы.
- Кыбла: компас по истинному северу с учётом магнитного склонения, расстояние до Каабы.

## Технологии

- [React Native](https://reactnative.dev) 0.81 + [Expo](https://expo.dev) SDK 54, TypeScript
- Expo Router (навигация), expo-notifications, expo-location, expo-audio
- [Adhan](https://github.com/batoulapps/adhan-js) — астрономический расчёт времени намаза и направления Кыблы
- AsyncStorage — все данные хранятся только на устройстве

## Запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npx expo start
```

Затем нажмите `a` для Android-эмулятора или отсканируйте QR-код в приложении Expo Go.

Проверка кода:

```bash
npm run typecheck
npm run lint
```

## Сборка

Для Google Play (файл `.aab`) через EAS:

```bash
npx eas-cli build --platform android --profile production
```

Тестовый APK: `--profile preview`. Подробная инструкция по публикации — в [docs/GOOGLE_PLAY.md](docs/GOOGLE_PLAY.md).

## Структура

```
app/            экраны (Expo Router): главная, Коран, дуа, тасбих, кыбла, профиль
components/     общие UI-компоненты и настройки времени намаза
data/           дуа, 99 имён, список сур, города, переводы интерфейса
hooks/          время намаза, уведомления, загрузка сур, настройки
lib/            расчёт времени намаза, календарь хиджры, даты
docs/           политика конфиденциальности и инструкция для Google Play
```

## Источники данных

- Время намаза в Кыргызстане — [muftiyat.kg](https://muftiyat.kg/ru/calendar/api/)
- Текст Корана, перевод Э. Кулиева, транслитерация, аудио — [Al Quran Cloud](https://alquran.cloud) / Islamic Network
- Кыргызский перевод смыслов Корана — Шамсуддин Хакимов, [QuranEnc.com](https://quranenc.com)
- Дуа — Коран и сборники хадисов (аль-Бухари, Муслим, Абу Дауд, ат-Тирмизи и др.)

Приложение не заменяет обращения к знающим людям. Если вы нашли ошибку в текстах или времени намаза — создайте issue.
