Как установить APK на Android
  1. Нажмите «Скачать APK» — загрузка начнётся сразу. Откройте файл из уведомления или из папки «Загрузки».
  2. Android спросит разрешение на установку из этого источника — разрешите для браузера.
  3. Нажмите «Установить», затем «Открыть».

Вопросы

Коротко о главном

Откуда берётся время намаза?

Для городов Кыргызстана приложение загружает официальное расписание Духовного управления мусульман КР. Если интернета нет, используется астрономический расчёт, настроенный так, чтобы совпадать с этим расписанием. Для России применяется метод ДУМ РФ, для других стран — расчёт по вашим координатам.

Приложение следит за моим местоположением?

Нет. Координаты используются на устройстве для расчёта времени и кыблы. Если вы в Кыргызстане и выбрали «Моё местоположение», координаты округляются примерно до 10 км и отправляются только на сервер муфтията для получения расписания. Ни аналитики, ни рекламных идентификаторов в приложении нет.

Насколько можно доверять текстам дуа?

У каждой дуа указан источник — аят или хадис с номером, чтобы вы могли проверить самостоятельно. Тексты без надёжного источника из приложения убраны. При любых сомнениях сверяйтесь со своим имамом или устазом.

Нужен ли интернет?

Нет для основного: расписание кэшируется, суры, которые вы открывали, сохраняются, дуа и 99 имён встроены в приложение. Интернет нужен только для аудио новых сур и обновления расписания.

Когда будет версия для iPhone?

Приложение написано так, что работает и на iOS, но публикация в App Store требует платного аккаунта разработчика Apple. Она запланирована после выхода Android-версии.

Как сообщить об ошибке или неточности?

Откройте issue на GitHub или напишите на почту, указанную на странице приложения. Замечания по религиозным текстам особенно важны — они проверяются в первую очередь.
