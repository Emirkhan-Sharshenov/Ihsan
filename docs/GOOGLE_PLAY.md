# Публикация в Google Play

## 1. Перед первой загрузкой (нельзя будет изменить потом)

- **Package name**: `kg.emirkhan.ihsan` (в `app.json` → `android.package`). После первой загрузки в Play сменить его нельзя — если хотите другой, поменяйте сейчас.
- **Название**: «Ихсан» — под иконкой на телефоне (`app.json` → `name`). В Google Play укажите «Ихсан: намаз, Коран, дуа» для русской страницы и «Ихсан: намаз, Куран, дуба» для кыргызской (до 30 символов). Название можно менять и после публикации.

## 2. Сборка

### Локально (без EAS)

Подпись берётся из `android/keystore.properties` (файл и сам `.jks` лежат вне репозитория — храните их копию!). Формат файла:

```properties
storeFile=C:/путь/к/ihsan-upload-key.jks
storePassword=…
keyAlias=ihsan-upload
keyPassword=…
```

```bash
npx expo prebuild --platform android
cd android
./gradlew bundleRelease   # .aab для Google Play
./gradlew assembleRelease # .apk для теста на телефоне
```

Если сборка упадёт с «Java heap space», увеличьте память в `android/gradle.properties`:
`org.gradle.jvmargs=-Xmx4096m -XX:MaxMetaspaceSize=1024m` (файл создаётся заново при `prebuild`).

### Через EAS (сборка на серверах Expo)

```bash
npm install -g eas-cli
eas login
eas build --platform android --profile production
```

Получится файл `.aab`. Номер версии (versionCode) EAS увеличивает сам. Для проверки на телефоне без Play: `eas build --platform android --profile preview` (APK).

**Проверьте на реальном Android-телефоне**: время намаза (сверьте с muftiyat.kg), уведомления (включите их и дождитесь ближайшего намаза), компас Кыблы, чтение и аудио сур, кыргызский язык.

**Краткое описание (до 80 символов)**
Время намаза по муфтияту КР, Коран с переводом, дуа, тасбих и кыбла

**Полное описание**
Ихсан — бесплатное приложение без рекламы и регистрации.

• Время намаза для Кыргызстана — по официальному расписанию Духовного управления мусульман Кыргызстана; для России — по методу ДУМ РФ; для других мест — астрономический расчёт по вашему местоположению.

• Уведомления о начале намаза и напоминания заранее.
• Коран: арабский текст, перевод смыслов Э. Кулиева (русский) и Ш. Хакимова (кыргызский), транслитерация, аудио (Мишари Рашид аль-Афаси). Открытые суры доступны без интернета.
• Дуа из Корана и достоверной Сунны с указанием источника.
• 99 имён Аллаха, тасбих, направление на Кыблу.
• Русский и кыргызский языки.

**Категория**: Образование (или «Образ жизни»). **Контакт**: ваш email.

## 4. Политика конфиденциальности

Опубликуйте `docs/privacy-policy.html` по публичной ссылке (например, GitHub Pages) и укажите ссылку в Play Console → «Политика конфиденциальности».

## 5. Анкета «Безопасность данных» (Data safety)

- Собирает или передаёт данные? **Да** (только местоположение, см. ниже).
- **Приблизительное местоположение** — *передаётся* (на muftiyat.kg, только для пользователей в Кыргызстане при выборе «Моё местоположение»), не собирается разработчиком, не является обязательным (можно выбрать город), цель: **функции приложения**.
- **Точное местоположение** — используется только на устройстве, не передаётся → в анкете не указывается как собираемое.
- Данные шифруются при передаче: **Да** (HTTPS).
- Можно запросить удаление: данные хранятся только на телефоне — удаляются вместе с приложением.

## 6. Остальные анкеты Play Console

- **Реклама**: нет. **Целевая аудитория**: 13+ (не выбирайте детей младше 13, иначе действуют дополнительные требования).
- **Возрастной рейтинг**: заполните анкету честно (насилия, азартных игр и т. п. нет).
- **Разрешения**: геолокация (время намаза и кыбла), уведомления. Точные будильники не используются, фоновой геолокации нет. Фоновые службы аудио удалены плагином `plugins/withoutAudioServices.js`, поэтому декларация foreground service не нужна.
- Новые личные аккаунты разработчика должны пройти **закрытое тестирование: не менее 12 тестировщиков в течение 14 дней** перед выпуском в продакшн.

## 7. Перед выпуском — проверка текстов

Тексты дуа и значения 99 имён проверены по источникам и исправлены, но **покажите раздел «Дуа» имаму или устазу** до выпуска — особенно транскрипцию и формулировки переводов.
